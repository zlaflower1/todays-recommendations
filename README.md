# TODAY'S RECOMMENDATIONS

하루를 시작하기 전에 확인하는 개인용 대시보드입니다.
**오늘의 운세**, **날씨와 대기질**, **옷차림 추천**을 한 페이지에서 보여줍니다.

- 배포 주소: (Vercel 주소를 여기에 붙여 넣으세요)
- 저장소: https://github.com/zlaflower1/todays-recommendations

## 주요 기능

### 1. 내 정보 입력
- 생년월일을 숫자 8자리로 입력합니다. (예: `19940509`, 입력하면 `1994.05.09`로 자동 정리)
- 양력 / 음력을 선택하고, 태어난 시간(오전·오후 / 시 / 분)을 입력합니다. 시간을 모르면 "태어난 시간을 몰라요"를 체크합니다.
- 잘못된 날짜(예: 2월 31일)는 안내 문구로 알려줍니다.
- 입력한 정보는 브라우저(`localStorage`)에 저장되어, 다시 열면 바로 운세가 나옵니다.
  `내 정보 초기화하기` 버튼으로 지우고 다른 정보를 입력할 수 있습니다.

### 2. 오늘의 운세
- **총운:** 세 문장으로 구성 (총운 + 하루 흐름 + 응원 한마디)
- **오늘의 행운 포인트:** 행운의 숫자, 색깔, 아이템, 시간
- **오늘의 레드 포인트:** 조심할 것, 피할 색깔
- **분야별 운:** 금전운, 애정운, 성취운

### 3. 날씨와 옷차림
- 현재 위치(위치 허용 시) 또는 서울(허용하지 않을 때)의 기온, 체감 온도, 최저/최고 기온, 강수 확률, 습도
- 초미세먼지(PM2.5) / 미세먼지(PM10) 등급을 색으로 표시하고, 등급에 따른 외출·마스크 안내
- 체감 온도 기준 옷차림 추천 (비·눈 오는 날의 우산, 일교차 안내 포함)

## 운세는 어떻게 정해지나요?

실제 사주 계산이 아니라 **재미를 위한 규칙 기반 방식**입니다.

1. `생년월일 + 양력/음력 + 태어난 시간 + 오늘 날짜`를 하나의 글자로 이어 붙입니다.
2. 이 글자를 해시 함수로 하나의 숫자로 바꿉니다.
3. 그 숫자를 문구 목록의 개수로 나눈 나머지로 문구를 고릅니다.

그래서 **같은 사람은 같은 날 몇 번을 봐도 같은 결과**가 나오고, 날짜가 바뀌면 결과도 바뀝니다.

## 사용 기술

| 구분 | 내용 |
|---|---|
| 화면 | HTML, CSS (Pretendard 폰트) |
| 동작 | JavaScript (프레임워크 없이) |
| 날씨 | [Open-Meteo Forecast API](https://open-meteo.com/) |
| 대기질 | [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) |
| 도시 이름 | [BigDataCloud Reverse Geocoding](https://www.bigdatacloud.com/) |
| 배포 | GitHub + Vercel |

모든 API는 무료이며 API 키가 필요 없습니다.

## 파일 구성

```
index.html   화면의 뼈대
style.css    디자인 (아이보리 / 화이트 / 딥 틸 / 세이지 버터)
script.js    날짜 표시, 운세 계산, 날씨·대기질 불러오기, 정보 저장
README.md    프로젝트 설명
```

## 실행 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.
(날씨와 폰트를 불러오려면 인터넷 연결이 필요하고, 위치 허용 창은 배포된 `https` 주소에서 더 안정적으로 동작합니다.)

## 한계와 알아둘 점

- **운세는 재미용입니다.** 정통 사주 풀이가 아닙니다.
- **음력은 양력으로 변환하지 않습니다.** 선택한 값이 운세 계산에 반영될 뿐입니다.
- **날씨는 기상 모델의 예측값**이라 실제 관측과 다를 수 있습니다.
- 위치를 허용하지 않으면 서울 기준으로 보여줍니다.
- 대기질 안내는 일반적인 권고를 바탕으로 한 참고용 문구입니다.
- 저장된 내 정보는 **사용 중인 브라우저에만** 저장됩니다.
